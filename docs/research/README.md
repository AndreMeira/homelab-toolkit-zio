# Design notes (drafts-of-record)

Exploratory rationale for this toolkit — *why* a thing is shaped the way it is, and the what-ifs considered
on the way there. These are **drafts kept as written**, not documentation: they record thinking at a point in
time and are not edited to stay true.

**[`../architecture/`](../architecture/) is the current state.** Where the two disagree, architecture wins.
Promotion — lifting the durable parts of a note into `architecture/` — is a deliberate editorial pass, and for
most of these it has not happened yet.

Notes that span repos or precede any code live in the homelab-wide `research/` instead; see
[`../../../DOCS.md`](../../../DOCS.md) for the split.
